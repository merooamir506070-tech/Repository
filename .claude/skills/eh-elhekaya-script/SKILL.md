# كاتب سكريبت فيديو الشرح («إيه الحكاية؟»)

الـskill ده بيكتب السكريبت والـstoryboard والعناوين بس. مش بيرسم ولا بيعمل render. الرسم والمونتاج بيتعملوا بأي أداة بتختارها.

## الخطوات

1. **اسأل عن الموضوع** في سؤال واحد: إيه الظاهرة أو الشيء اللي هيتشرح؟ ولو فيه أرقام أو حقايق معروفة، اطلبها.
2. **اكتب السكريبت** بالشكل ده بالظبط:
   - **السطر 0:** hook بصري/معلومة صادمة لكن صحيحة، من حاجة المشاهد يعرفها.
   - **السطر 1 و2:** سؤالين يفتحوا فجوة فضول، من غير تكرار نفس المعنى.
   - **السطور التالية:** شرح سببي متدرّج: المشكلة ← المبدأ الأساسي ← إزاي بيشتغل خطوة بخطوة ← نتيجة أو مفاجأة ← تطبيق في الحياة.
   - كل سطر فكرة واحدة قابلة للتحويل إلى لقطة واضحة، وفيه فعل أو تغيير بصري يمكن رسمه.
   - **الخاتمة:** ارجع للـhook وأجب عنه بوضوح. سؤال التفاعل («قولولنا، عايزين نشرحلكم إيه المرة الجاية؟») اختياري: اسأل المستخدم قبل ما تحطه.
   - الإجمالي: من 22 لـ30 سطر حسب تعقيد الموضوع، ومدة صوت مستهدفة 100–120 ثانية. لا تحشو معلومات لمجرد الوصول لعدد كلمات.
   - **ممنوع** تكتب عبارة «إيه الحكاية؟» أو كلمة «حكاية» في أي سطر من السكريبت.
3. **قواعد الكتابة:**
   - عامية مصرية بسيطة ودودة (مش فصحى إلا لو المستخدم طلبها).
   - جملة واحدة في كل سطر، ومن غير أقواس أو قوائم.
   - نوّع طول الجمل والإيقاع؛ تجنّب تكرار «وبعدين» و«تخيل» أو نفس البناء في كل سطر.
   - اشرح المصطلح العلمي ببساطة عند أول ظهور، ولا تستخدم تشبيهًا كأنه حقيقة علمية.
   - لا تخترع أرقامًا أو ادعاءات. لو معلومة غير مؤكدة، علّمها في قائمة التحقق بدل عرضها كحقيقة.
   - لا تكتب عبارات بصرية عامة مثل «نشوف شرح»؛ اكتب ما الذي يظهر ويتحرك تحديدًا.
   - الأرقام تتكتب كلمات لو هتتقرا: «تسعة وتسعين» مش 99.
   - الأسماء الإنجليزية زي GPS وLCD تفضل بحروف لاتينية.
4. **تحقق من الحقايق** وقول للمستخدم أي حقيقة مفاجئة محتاجة يتأكد منها بنفسه.
   - افصل بين الحقيقة العلمية والتشبيه البصري.
   - أي رقم أو ادعاء غير موثّق يتحط في قائمة «محتاج تحقق»، ومايتقالش بصيغة مؤكدة.
   - لو الموضوع طبي/تاريخي/تقني وفيه معلومة حساسة أو متغيرة، ابحث عن مصدر موثوق قبل صياغة الادعاء.
5. **اعمل الـstoryboard:** لكل سطر، اكتب جدول بالأعمدة دي:
   - رقم السطر
   - المشهد (الشخصيات والمكان والحركة اللي شغالة طول الوقت)
   - الكاميرا (ثابتة، بتقرب، بتبعد)
   - الكلمات المفتاحية اللي تتلوّن أصفر في الترجمة
   - المؤثر الصوتي (whoosh قبل كل سطر، وبعدين مؤثر حسب الحركة)
6. **اعمل العناوين:** 3 عناوين لـTikTok، وعنوان واحد لفيسبوك مع وصف فيه نقاط، وعنوان لـYouTube Shorts ينتهي بـ#shorts.
7. **راجع الجودة قبل التسليم:** هل البداية تشد؟ هل كل معلومة بتقود للي بعدها؟ هل اتجاوب السؤال الأساسي؟ احذف الحشو والتكرار.
8. **اختبار قابلية التحريك:** قبل تسليم كل سطر، اسأل: هل أقدر أرسم فعلًا واضحًا يشرح الجملة؟ لو لا، أعد صياغة الجملة أو اقترح لقطة توضيحية دقيقة.
9. **اختبار الإيقاع:** نوّع الجمل القصيرة والطويلة، وخلّي لحظات الكشف أو المفاجأة لها مساحة صوتية وبصرية. أرفق تقدير مدة القراءة وقائمة الحقائق المطلوب التحقق منها.

## قواعد مهمة للـstoryboard
- ما يكونش فيه مشهد واقف. لازم فيه حاجة شغالة طول الوقت (عربيات، أمواج، أضواء بتومض، دوائر بتنبض).
- اختار بداية بشيء المشاهد يعرفه (موبايل في إيد، تلفزيون في الصالة) وبعدين اسحب الكاميرا للشرح.

## الشكل الناتج
1. السكريبت في code block واحد، سطر لكل جملة.
2. الـstoryboard جدول markdown.
3. العناوين كل واحد في code block منفصل.
4. في الآخر سطر بيقول الحقايق اللي محتاجة تأكيد.
